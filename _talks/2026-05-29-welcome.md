This is where I'll drop the more informal stuff — slides from talks I give, notes
from seminars and reading groups, and half-baked ideas that aren't polished enough
for a full blog post.

Each entry here works just like a blog post: write Markdown, add math with `$...$`,
embed images, link to slides or recordings. To add a new one, drop a file in the
`_talks/` folder named `YYYY-MM-DD-title.md` with the same front matter as this page.

A few optional front-matter fields:

- `venue:` — where you gave the talk (shown in the meta line).
- `redirect:` — point an entry at an external URL (e.g. a slides PDF) instead of a page.
- `thumbnail:` — a small image shown next to the entry in the list.

That's it. More casual, less ceremony.
